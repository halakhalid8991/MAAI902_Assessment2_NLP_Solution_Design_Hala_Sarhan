# MAAI902_Assessment2_NLP_Solution_Design_Hala_Sarhan
NLP pipeline for spare parts procurement documents: classifies documents, extracts parts, suppliers and dates, flags urgency, and answers questions with a Qwen2.5 LLM that cites sources or refuses. Hybrid retrieval (MiniLM + FAISS) on a Colab T4 GPU -  MAAI 902.
